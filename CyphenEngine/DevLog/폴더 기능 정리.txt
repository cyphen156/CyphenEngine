CyphenEngine
	엔진 실행 파일 프로젝트입니다.
	엔진 본체, 플랫폼 진입점, 공통 기반 계층, 개발 기록을 포함합니다.

	/.github
		GitHub 저장소용 설정을 관리합니다.

	/DevLog
		개발 기록, 구조 메모, 작업 TODO를 관리합니다.

	/Resources
		실행 시 사용하는 테스트 / 샘플 파일 리소스를 관리합니다.

	/Source
		엔진 실행 파일의 실제 소스 루트입니다.

		/Build
			빌드 타겟, 플랫폼 정의, export 규약, 공통 빌드 정책을 관리합니다.

		/Content
			엔진이 사용하는 콘텐츠 파일 디코딩 경로를 관리합니다.

			/Private
				공통 content decode 구현과 플랫폼별 decode leaf를 관리합니다.

			/Public
				Content 계층의 공개 계약을 관리합니다.

		/Core
			Runtime과 Editor 양쪽에서 사용하는 OS 비종속 엔진 기반 계층입니다.
			Core는 Windows / Linux API를 직접 호출하지 않습니다.

		/Editor
			Editor 타겟 전용 계층입니다.
			현재는 향후 editor runtime 구성을 위한 자리입니다.

		/Engine
			CyphenEngine 최상위 엔진 인스턴스와 실행 상태를 관리합니다.
			Engine은 화면 출력 backend를 직접 소유하지 않습니다.

		/HAL
			Core / Engine 내부 구현과 Platform 구현 사이의 내부 계약을 관리합니다.

		/Modules
			엔진 내부 모듈 계약과 런타임 바인딩을 관리합니다.
			DLL / SO 내부의 구체 backend 구현은 솔루션 루트의 Modules 하위 프로젝트에 둡니다.

		/Platform
			플랫폼별 진입점과 OS 종속 구현을 관리합니다.

			/Linux
				Linux main, POSIX file I/O, clock_gettime, dlopen / dlsym, X11 windowed launch를 관리합니다.

			/Windows
				Windows entry, Win32 file I/O, timer, LoadLibrary / GetProcAddress, windowed launch를 관리합니다.

		/Resource
			엔진 런타임 리소스 타입과 CPU-side 리소스 표현을 관리합니다.
			GPU resource 생성과 업로드는 Renderer 모듈 책임입니다.

		/Test
			Debug 빌드에서 엔진 내부 기준선을 검증하는 테스트 계층입니다.
			Runtime / Engine 및 Release 빌드에서는 의존하지 않습니다.

			/Runtime
				Object composition과 World 합류를 실제 Runtime 예제 객체로 검증합니다.

	pch
		사전 컴파일 헤더 및 공통 빌드 환경입니다.

CMake
	Linux / CMake 빌드 공통 규칙과 target helper를 관리합니다.

Docs
	외부 설명용 아키텍처 문서를 관리합니다.

Modules
	엔진 실행 파일 밖의 선택 모듈 backend 프로젝트를 관리합니다.

	/Renderer
		Renderer 모듈의 backend 구현 프로젝트들을 관리합니다.
		반복 backend 모듈은 같은 역할을 공유하므로 이름만 나열합니다.

		- CyphenRendererDx11
		- CyphenRendererOpenGLES
		- CyphenRendererVulkan
